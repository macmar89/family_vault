## Security & Password Hashing

Family Vault prioritizes the security of your credentials. Instead of using legacy algorithms like BCrypt or PBKDF2, we employ **Argon2id**, the winner of the Password Hashing Competition (PHC).

### Security Philosophy

We chose **Argon2id** for several critical reasons:
- **ASIC/GPU Resistance**: Unlike many other algorithms, Argon2 is designed to be memory-hard, making it exceptionally expensive to crack using specialized hardware like GPUs or ASICs.
- **Side-Channel Protection**: The 'id' variant of Argon2 provides a balance between resistance against side-channel attacks (data-independent memory access) and brute-force attacks (data-dependent memory access).
- **Modern Standard**: It is currently considered the gold standard by NIST and the global cryptographic community.

### Adaptive Security

Family Vault is designed to be truly cross-platform—running reliably on everything from a low-power **Raspberry Pi Zero** to **high-performance enterprise servers**. To achieve this, we've implemented the "Adaptive Security" model:

Through `.env` configuration, users can fine-tune the hashing complexity (Memory, Time, and Parallelism) to perfectly match their specific hardware capabilities while maintaining the highest possible security margin.

### Recommended Settings

Depending on your host environment, we recommend the following profiles:

| Profile | Target Hardware | Memory Cost (Env) | Memory (RAM) | Time Cost | Parallelism |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Low-End** | Raspberry Pi / IoT | `16384` | 16 MB | `2` | `1` |
| **Standard** | Standard VPS / Cloud | `65536` | 64 MB | `3` | `4` |
| **High-End** | Dedicated Server | `131072` | 128 MB | `4` | `4` |

### Configuration Example

Add these variables to your `.env` file to customize the hashing behavior:

```bash
# Argon2id Hashing Settings
# Memory cost in KB (e.g., 65536 = 64MB)
ARGON2_MEMORY=131072

# Number of iterations over memory
ARGON2_TIME=4

# Degree of parallelism (number of threads)
ARGON2_PARALLELISM=4
```

> [!IMPORTANT]
> **Backward Compatibility**: Changing these values only affects **newly created** passwords or password changes. Family Vault automatically identifies the hashing parameters used for existing hashes, ensuring that older passwords remain valid and verifiable even after you upgrade your security settings.

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.
